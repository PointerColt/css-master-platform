Chapter 2: The Cascade, Specificity, and Inheritance

Topic 2.2: Value Inheritance

When styling a webpage, you do not want to write the same design rules over and over. If you decide to change your website's main font from Arial to Georgia, you shouldn't have to hunt down every heading, paragraph, list, and list item to update them manually.

To solve this problem, CSS relies on a mechanism called Inheritance.

The Family Tree of CSS

To understand inheritance, let's look at a family tree analogy.

Just as you might inherit your eye color or hair texture from your parents, HTML elements inherit visual traits from their parent containers.

In HTML, elements are nested inside one another, forming a clear parent-child hierarchy:

  • body
              <---  Great-Grandparent
    • main
                <---  Grandparent
      • div
                  <---  Parent
        • p
                    <---  Child

In CSS, if you apply a typography style to an ancestor element (like the <body> or a <main>), that style automatically flows down and applies to its descendants (like the <div> or <p>tag).

CSS Propeties: Inherited vs non-inherited

Not all CSS properties are inherited. CSS divides properties into two categories based on common-sense layout rules:

Inherited Properties

(Typography & Text Styles)

  • font-family
  • font-size
  • font-weight
  • color
  • text-align
  • text-indent
  • text-transform
  • line-height

Non-Inherited Properties

(Box Model & Layout Styles)

  • width
  • height
  • border
  • background-color
  • margin
  • padding
  • display

Why are layout properties non-inherited?

Imagine if you styled your <body> to have a 20px margin and a solid black border. If layout properties were inherited, every single paragraph, link, and heading inside your body would also get a 20px margin and a border! Your webpage would become a cluttered, unreadable mess.

Example Code

Instead of declaring your font family and text color on every individual selector, you can target the body tag at the very top of your stylesheet.

CSS
/* We declare styles once on the parent body tag */
body {
    font-family: sans-serif; /* Inherited by all descendants */
    color: #2c3e50;         /* Inherited by all descendants */
}

/* Specific elements will inherit these styles automatically */
p {
    /* No need to declare font-family or color here! */
    margin: 15px; /* Does NOT inherit to nested tags */
}

Overriding Inherited Values

If you want a child element to look different from its parent, you can override the inherited value by targeting the child directly. Direct declarations always defeat inherited styles.

CSS
body {
    color: blue; /* All text defaults to blue */
}

/* Overrides the inherited color for H1 tags only */
h1 {
    color: red; /* Headings will render red */
}

The inherit Keyword

Sometimes browser default styles (like blue hyperlink text) prevent elements from inheriting your parent designs. To force an element to inherit a parent style, use the inherit keyword.

CSS
/* Set text color on the parent navigation bar */
.nav-bar {
    color: green;
}

/* Force links to inherit the green color, ignoring browser defaults */
.nav-bar a {
    color: inherit;
}
